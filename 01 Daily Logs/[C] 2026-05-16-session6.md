## Training Block Generator — Complete Overhaul

### Root causes of bodyweight-only blocks
1. `getAvailable()` goal filter was too strict — comm/elite exercises tagged build/strength were excluded for fat-loss/recomp users because they lacked fat-loss tag
2. `pickEx()` preferred animated exercises — all animations are bodyweight, so it always picked push-ups over barbell bench
3. No tier preference — bodyweight exercises appeared first in array, got picked first

### Fixes applied
1. **`getAvailable()` — smart goal filter**: Open styles (fat-loss/recomp/build/strength/general/athletic) now accept any exercise at the right tier. Tier + sets/reps scheme handles the goal, not exercise selection. Yoga/pilates/hyrox still filtered strictly.
2. **`pickEx()` — sort by tier descending**: Candidates sorted by TIER_RANK so elite gym users always get elite exercises first.
3. **Exercise goal patches**: Added fat-loss/recomp tags to 13 key exercises (T-Bar Row, Trap Bar DL, Pendulum Squat, Leg Press, Lat Pulldowns, etc.)
