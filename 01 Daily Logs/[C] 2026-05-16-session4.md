### Block Generator (`buildBlock()` function — 272 lines)
- `profileToTier()` — maps gym type/equipment → equipment tier
- `goalStyle()` — maps goal text → programming style (fat-loss/build/strength/recomp/athletic/hyrox/yoga/pilates/beginner)
- `weekStyle()` — sets/reps/rest per goal AND phase (vol→vol+→intensity→peak)
- `getAvailable()` — filters library by tier, difficulty, goal, injuries
- `pickEx()` — selects best exercise per movement pattern, prefers SVG-animated ones
- `buildBlock()` — generates full training split (1-6 day templates), yoga/Pilates special templates
- `generateAndSaveBlock()` — wired into wizNext() after intake completion
- `initApp()` — loads saved block from localStorage on startup
